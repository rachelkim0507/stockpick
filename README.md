# 📈 단타·중타 추천 (폰 앱 + 클라우드)

PC 없이 폰만으로 쓰는 주식 추천 앱이에요.

- **GitHub Actions**가 평일 08:37, 15:37(한국시간)에 코스피·코스닥 상위 300종목을 분석해요.
- 단타(1~5일)와 중타(2~6주)를 각 1~2개 골라 **매수가·목표가·손절가**를 정해요.
- **ntfy** 앱으로 폰에 푸시 알림을 보내요.
- 장중에는 20분마다 가격을 확인해서 매수가·목표가·손절가에 닿으면 알림을 보내요.
- 결과는 **폰 앱**(GitHub Pages, 홈 화면에 설치)에서 차트와 함께 볼 수 있어요.

## 폰에서 처음 설정
1. 저장소 **Settings → Pages** → Source: `Deploy from a branch`, Branch: `main` / 폴더 `/docs` → Save
2. 1~2분 뒤 `https://아이디.github.io/stockpick/` 접속
   → 안드로이드는 크롬 ⋮ → **홈 화면에 추가**, 아이폰은 사파리 공유 → **홈 화면에 추가**
3. 앱의 **설정** 탭 → ntfy 앱 설치 → 이름 복사해서 구독
4. 저장소 **Actions** 탭 → `주식 추천` → **Run workflow** → mode `test` 로 알림 확인, `analyze` 로 첫 분석

## 바꾸고 싶을 때
`config.json` 을 GitHub에서 연필 아이콘으로 수정하세요.
- `top_n`: 분석 종목 수 · `picks_each`: 단타/중타 각 추천 개수(1~2) · `watch_alert`: 장중 가격 알림

## 주의
- 일봉(하루 단위) 기준이라 분 단위 초단타용은 아니에요. GitHub 자동 실행은 몇 분씩 늦을 수 있어요.
- 과거 데이터 기반 **참고용 신호**이며 수익을 보장하지 않아요. 손절가는 꼭 지키세요.
